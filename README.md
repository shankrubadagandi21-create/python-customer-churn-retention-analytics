Customer Churn and Retention Analytics

Project Overview

This project analyses customer churn and retention patterns for a subscription-based company using Python.

The main objective is to understand why customers leave the company and identify customer segments with higher churn rates.

Business Objectives

- Calculate customer churn percentage.
- Analyse churn by contract type.
- Understand the relationship between customer tenure and churn.
- Compare monthly charges of churned and retained customers.
- Analyse customer support interactions.
- Identify factors associated with customer churn.
- Build a machine learning model to predict customer churn.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Dataset

The project uses a synthetic customer churn dataset containing 10,000 sample customer records.

Key columns:

- customer_id
- tenure_months
- contract_type
- monthly_charges
- payment_method
- support_calls
- usage_level
- churn

Project Steps

1. Import Python libraries.
2. Create and load the dataset.
3. Inspect and clean customer data.
4. Handle missing values.
5. Calculate churn rate.
6. Analyse churn by contract type.
7. Analyse customer tenure.
8. Compare monthly charges.
9. Analyse support calls.
10. Create data visualisations.
11. Generate business insights.
12. Build a Logistic Regression model.

Machine Learning

A Logistic Regression model is used as an optional predictive extension to classify customers into churn and non-churn categories.

Model evaluation includes:

- Precision
- Recall
- F1-score
- Support

Business Recommendations

- Improve customer retention strategies.
- Monitor customers with higher churn patterns.
- Review subscription plans.
- Improve customer support services.
- Provide targeted retention offers.

Expected Outcome

The project helps understand customer churn patterns and supports data-driven customer retention decisions.
